# TEAM

## Team Lead / Backend / DevOps

Responsibilities:
- Project architecture
- Backend
- API
- Database
- Docker
- Deployment
- Git workflow
- Code review
- Integration

Must coordinate major architectural changes with the team.

## Frontend Developer

Responsibilities:
- UI
- UX
- Components
- Pages
- API integration
- Loading and error states
- Responsive design

Must not change backend API contracts without agreement.

## AI Engineer

Responsibilities:
- AI API integration
- LLM
- Prompt engineering
- Structured output
- RAG
- Embeddings
- OCR / CV
- AI evaluation

Must not expose API keys or silently change public API contracts.

## Integration / Hardware Developer

Responsibilities:
- Hardware
- Sensors
- Device communication
- Data collection
- Integration with backend

If hardware is not required, this role can focus on testing and system integration.
