# AI AGENT RULES

You are working on a hackathon project.

## Before coding

1. Read README.md.
2. Read docs/ARCHITECTURE.md.
3. Read docs/API.md.
4. Read docs/CONTRIBUTING.md.
5. Understand the existing project structure.

## General rules

- Do not rewrite the architecture without approval.
- Do not modify unrelated files.
- Keep changes small and focused.
- Do not delete working code without a clear reason.
- Do not install dependencies without explaining why.
- Do not change API contracts silently.
- Never hardcode API keys or secrets.
- Use environment variables for secrets.
- Follow the existing project structure.
- Prefer simple solutions over unnecessary complexity.

## Git rules

- Never commit directly to main.
- Work in a feature branch.
- Make small, meaningful commits.
- Never force push.
- Do not rewrite Git history unless explicitly requested.

## Before finishing

1. Check git diff.
2. Run tests.
3. Fix obvious errors.
4. Explain what files were changed.
5. Explain what was implemented.
6. Mention anything that remains unresolved.
